# Сторона Закона — банкротство физических лиц

Статический лендинг юридической группы «Сторона Закона». Главная страница находится в `index.html`; стили, скрипт и изображения лежат рядом. Установка зависимостей и сборка не нужны.

## Публикация через GitHub Pages

Для первого запуска откройте **Settings → Pages** в аккаунте владельца, выберите **GitHub Actions** как источник публикации. Затем откройте **Actions → Publish website → Run workflow**. После успешного выполнения сайт будет доступен по адресу [lukos001.github.io/bolotaev](https://lukos001.github.io/bolotaev/). Дальнейшие изменения ветки `main` будут публиковаться автоматически.

Судебные акты и фотографии взяты с публичных сайтов компании [storona-zakona.ru](https://storona-zakona.ru/) и [storonazakona.ru](https://storonazakona.ru/). Число отзывов Яндекса зафиксировано на странице по состоянию на 16 октября 2026 года и со временем может измениться.
